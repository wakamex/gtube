gtube is a native YouTube Music player with a music visualizer: one small executable for Linux or Windows that searches YouTube Music, plays your liked music, playlists and radios, and streams the audio with its own copy of [yt-dlp](https://github.com/yt-dlp/yt-dlp). The executable is about 4 MB and each download about 1.8 MB, and while playing it uses about 90 MB of RAM on Windows. This is its first release.

## Downloads

- `gtube-v0.1.0-x86_64-linux.tar.gz`: the `gtube` executable for x86-64 Linux with the [GNU C Library (glibc)](https://www.gnu.org/software/libc/) 2.27 or newer (Ubuntu 18.04, Debian 10, RHEL, Rocky and Alma Linux 8, Fedora 28 and later). It needs [libcurl](https://curl.se/libcurl/), which Ubuntu, Debian, Fedora, Arch, openSUSE and Mint desktops all install, and an X11 or Wayland desktop; the sign-in window uses [WebKitGTK](https://webkitgtk.org/) (GTK 3's `libwebkit2gtk-4.1` or GTK 4's `libwebkitgtk-6.0`) when it is installed.
- `gtube-v0.1.0-x86_64-windows.zip`: `gtube.exe` for 64-bit Windows 10 and 11, signing in through the [WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) runtime that Windows already has.
- `SHA256SUMS`: checksums of both archives.

Each archive also holds the visualizer's GPU program (`gtube.gpu` or `gtube.exe.gpu`, which must stay next to the executable), the README, the MIT `LICENSE`, and a `licenses` folder with the licenses of the code compiled in: the [Bend](https://github.com/bendlang/bend) runtime, [gesso](https://github.com/wakamex/gesso), [Simple DirectMedia Layer (SDL)](https://www.libsdl.org/) 3, [Opus](https://opus-codec.org/) and [stb](https://github.com/nothings/stb), plus SDL's Wayland code on Linux and the WebView2 headers on Windows.

On first run gtube downloads yt-dlp into its data folder and keeps it updated, along with [Deno](https://deno.com/) for yt-dlp unless Deno, Node or Bun is already installed. The [README](https://github.com/wakamex/gtube/blob/v0.1.0/README.md) covers keys, sign-in, the visualizer and options.

## Verifying a download

Every asset is attested by the release workflow:

```sh
gh attestation verify gtube-v0.1.0-x86_64-linux.tar.gz --repo wakamex/gtube \
  --signer-workflow wakamex/release-actions/.github/workflows/binary-release.yml
```
