This release fixes the Bend visualizer effects, sign-in and radio. The Bend effects no longer crash gtube when auto mode or a new track switches to them, no longer run out of memory after hours, and draw on the CPU when no GPU is found instead of closing gtube. Running two copies of gtube on the same profile no longer gets you signed out, and a radio no longer queues the same song twice under different videos.
